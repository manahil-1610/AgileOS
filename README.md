# AgileOS

AgileOS is a lightweight web-based dashboard for agile team planning and wellbeing management.

## Features

* Employee management
* Capacity overview
* Mood tracking
* Project assignment
* Responsive UI

## Built with

* Python
* Flask
* SQLAlchemy
* SQLite
* HTML
* CSS
* JavaScript

## Focus

Designed with accessibility, universal design principles, and WCAG awareness.
